# Space_shooting_game_in_C++

- Dans votre terminal IDE, compiler à partir de la commande : ```g++ *.cpp -o shooting_game```

- Finalement, il suffit de lancer le programme : ````./shooting_game.exe```

# Comment jouer ?

- Appuyer sur la lettre ```q``` pour avancer à gauche
- Appuyer sur la lettre ```d``` pour avancer à droite
- Appuyer sur ```backspace``` pour tirer une balle

Bien évidemment, les touches peuvent être modifiées via le code si le clavier n'est pas AZERTY.
